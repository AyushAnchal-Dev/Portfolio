# Ayush Anchal — Developer Portfolio

A one-page interactive portfolio showcasing my projects, skills, and development journey.

🌐 **Live:** [View Portfolio](#) *(deploy to get your link)*
📦 **GitHub:** [AyushAnchal-Dev](https://github.com/AyushAnchal-Dev)

---

## ✨ Features

- **Interactive 24-Hour Timer** — Centerpiece countdown with orbiting project sticky notes
- **3D Tilt Effects** — Perspective-based hover animations on skill nodes and project cards
- **Spray Paint Animations** — Neon text reveal effects on load and hover
- **Frosted Glass Panels** — Semi-transparent panels with scrolling code snippets
- **Skills Constellation** — 30+ technologies displayed with official icons and brand colors
- **10 Featured Projects** — Each with live demo links, GitHub repos, and tech stack tags
- **Copy-to-Clipboard** — One-click copy for email, LinkedIn, and GitHub links
- **Resume Download** — Direct PDF download button
- **Scroll Reveal** — Staggered entrance animations powered by IntersectionObserver
- **Fully Responsive** — Optimized for mobile, tablet, and desktop
- **Zero Build Step** — No npm, no React, no framework — pure HTML + CSS + JS

## 🚀 Quick Start

No installation required. Just open in a browser:

```bash
# Clone the repo
git clone https://github.com/AyushAnchal-Dev/portfolio.git
cd portfolio

# Open in browser
start index.html        # Windows
open index.html         # macOS
xdg-open index.html     # Linux
```

Or use a local server for full functionality:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .

# Then open http://localhost:8000
```

## 🌍 Deployment

### GitHub Pages
1. Push this folder to a GitHub repository
2. Go to **Settings → Pages → Deploy from branch**
3. Select `main` branch, root directory
4. Your site will be live at `https://yourusername.github.io/repo-name/`

### Vercel
1. Import your GitHub repo on [vercel.com](https://vercel.com)
2. Set root directory to `./` (or `portfolio/` if nested)
3. No build command needed — it's static
4. Deploy → get your live URL

### Netlify
1. Drag and drop the `portfolio/` folder on [netlify.com](https://netlify.com)
2. Or connect your GitHub repo
3. No build settings needed
4. Deploy → get your live URL

## ⚡ Performance

- **Zero npm dependencies** — no `node_modules`, no build step

- **Target page weight:** < 200KB (excluding fonts)
